# PROMAKSS

Official website of PROMAKSS.

PROMAKSS is a single-page official website for the music project. It presents the current release and provides direct links to the available streaming platforms and social profiles through a focused, mobile-first experience.

## Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS

## Local Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```
